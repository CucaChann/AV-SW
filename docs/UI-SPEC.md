# UI Specification

## Product feel
Professional design software with a calm, information-dense workspace. Inspiration may come from CAD tools, UniFi Design Center, and modern AV design software, while keeping the workflow approachable.

## Primary workspace
Three-column layout:
1. Left system/tool sidebar
2. Central floorplan/elevation canvas
3. Right properties/issue inspector

## Primary system layers
- Lighting
- Lutron
- QTL
- Shades
- Network
- Audio
- Video
- Infrastructure
- Coordination

## Top bar
- Project name
- Floor/revision selector
- Save state
- Design Check
- Export
- Revision status

## Left panel
- System layer selector
- Product/device library
- Drawing tools
- Room/zone tools

## Canvas
- PDF underlay
- Pan/zoom
- Measurement
- Scale calibration
- Select/move/rotate/delete
- Layer visibility
- Snap/align later

## Right panel
Context-sensitive properties:
- Product/model
- Room
- Coordinates
- Mounting/AFF
- Wiring/power
- Status
- Notes
- Related issues
- Required accessories

## Important views
- Dashboard
- Project workspace
- Product library
- Design Check
- BOM/schedules
- Quote comparison
- Issues/TBDs
- Revision comparison
- Elevation designer

## Initial UX principle
Get a crude but functional workspace running first, then refine visual design in Figma.
